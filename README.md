# PCB Defect Classification

Multi-device PCB defect detection using Self-Supervised Few-Shot Reinforcement Learning with comprehensive benchmarking across edge device profiles.

## Overview

This project implements an intelligent PCB defect classification system that combines:
- **Self-Supervised Learning** for feature extraction without labeled data
- **Few-Shot Learning** for classification with minimal examples
- **Reinforcement Learning** for adaptive model improvement
- **Edge Device Optimization** with comprehensive benchmarking
